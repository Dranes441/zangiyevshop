# Dranes Stars Shop — Telegram-бот

## Возможности
- Каталог пакетов с редактируемыми ценами в сумах.
- Сбор Telegram username получателя.
- Инструкция по переводу на карту администратора.
- Получение фото чека.
- Уведомления администратору о старте, заказах, сообщениях и отправленных медиа.
- Админ-кнопки: подтвердить оплату, отклонить чек, отметить заказ выполненным.
- SQLite-история заказов и действий.
- Команда `/reply USER_ID текст` для ответа клиенту из аккаунта администратора.

## Установка на MacBook

1. Установи Python 3.11 или новее.
2. Создай бота через `@BotFather` командой `/newbot`.
3. Скопируй папку проекта на Mac и открой Terminal внутри папки.
4. Выполни:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

5. Открой `.env` и заполни `BOT_TOKEN`, `ADMIN_ID`, `CARD_NUMBER` и `CARD_HOLDER`.
6. Запусти `python bot.py`.
7. Открой бота и отправь `/start`.

Чтобы узнать свой Telegram ID, временно укажи `ADMIN_ID` как `123456789`, запусти бота и отправь `/myid` от своего аккаунта. Затем останови бота, вставь свой настоящий ID в `.env` и запусти снова. Более простой альтернативный способ — узнать ID через надёжного ID-бота. Не публикуй токен.

## Настройка пакетов

В `bot.py` найди словарь `PACKAGES` и измени Stars/цены. Цены в примере демонстрационные.

## Важные ограничения

- Это обработчик заказов с ручной проверкой перевода, а не автоматический банковский эквайринг.
- Скриншот чека не подтверждает поступление денег. Проверяй банковское приложение.
- Кнопка «Подтвердить оплату» отмечает только факт ручной проверки перевода.
- Кнопка «Отметить выполненным» означает, что администратор вручную подтверждает исполнение заказа. Бот сам не зачисляет Stars на чужой аккаунт.
- Для автоматического пополнения нужен отдельно разработанный и проверенный модуль через поддерживаемый Telegram API.
- Не проси и не храни PIN, CVV, пароли, SMS-коды или коды входа Telegram.
- В боте есть уведомление, что сообщения и чеки передаются администратору. Не пересылайте личные данные клиентов без необходимости.
- Для реальной работы не запускай бот только на ноутбуке: при остановке компьютера бот отключится. Нужен сервер/VPS с безопасным хранением `.env`.
- Перед коммерческим запуском проверь правила банка/платёжного провайдера и юридические требования к приёму платежей.
